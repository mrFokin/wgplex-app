# A3 — окно

Статус: план согласован; формат лога — slog TextHandler (`level=INFO`). Ветка `a3-window` от `master`.

**Цель:** окно SwiftUI по design 5: боковая панель (Туннели, Правила, Диагностика, Логи), панель действий, баннер, папка конфига. Меню A2: «Открыть Wgplex…» и строка проблемы начинают открывать окно на нужном разделе.

## Решения

1. **Логика в `WgplexKit` (без AppKit/SwiftUI, XCTest):**
   - `WindowModel.make(from: EngineState)` — баннер (приоритет: ошибка конфига → демон недоступен → пауза → правило на резерве; «доступна новая версия» — A4), состояние панели действий (активность по `can_control`/`paused`), строки списка туннелей и правил, детали туннеля (endpoint, интерфейс и адрес, handshake, трафик, маршрутов, проверка), форматирование байтов и «handshake N с назад».
   - `LogTail` — хвост файла (последние N КБ), дочитывание с запомненного смещения, обрезка по строке, разбор уровня (`level=`), фильтр по уровню и подстроке. Чтение через замыкание-источник, чтобы тестировать без файлов.
   - `ConfigDirAccess` — доступен ли `config_dir` на чтение текущему пользователю (замыкание `isReadable`), иначе текст «Конфиг правит администратор» с путём.
2. **Окно (`Sources/Wgplex`):** `WindowController` (NSWindow + `NSHostingView`), `NavigationSplitView` (macOS 13), по одному View на раздел. Активация `.regular` пока окно открыто, возврат в `.accessory` при закрытии (design 5).
3. **Состояние:** общий `StatusPoller` (A2) отдаёт `EngineState` и меню, и окну; пока окно открыто — опрос раз в 1,5 с. `explain` и `routes` — по запросу из раздела «Диагностика» (поле + кнопка; таблица маршрутов по кнопке «Обновить»).
4. **Действия:** панель (Приостановить/Возобновить, Выключить все, Перечитать конфиг) и переключатели туннелей — те же вызовы `Client`, что в меню; ошибки — строкой в баннере (`actionErrorText`). «Перечитать» показывает результат (`ApplyResult`: применено / N ошибок) в окне, без уведомления (design 7).
5. **Логи:** без права чтения `log_path` — «нужно членство в группе <control_group>» (`control_group` из статуса). Чтение файла — `FileHandle` на фоновой задаче, дочитывание раз в 1 с, пока раздел открыт; поиск и фильтр по уровню — по загруженному буферу (предел ~2000 строк).
6. **Не в A3:** настройки (⌘, и переопределение пути к сокету — убрано по решению пользователя; окно настроек появится в A4 с автозапуском, уведомлениями и проверкой обновлений), автозапуск, уведомления, проверка обновлений, `Info.plist`/бандл (значок в Dock — по `setActivationPolicy`, работает и под `swift run`).

## Правки design.md в этой ветке

Раздел 5: из «Настроек» убрать «путь к сокету» (остаются запуск при входе, уведомления, проверка обновлений). Если формат лога движка или поля `status.get` потребуют уточнения раздела 5 — согласовать.
